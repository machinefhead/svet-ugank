# 09 — GitHub in Codex

Repo: `machinefhead/svet-ugank`, zaseben, `main` je zaščitena **po dogovoru** (za zdaj ni nastavljena GitHub branch protection). Spremembe pripravljamo v vejah in PR, pred združitvijo jih pregleda lastnik.

Pravila:
1. Pred delom preberi `AGENTS.md`, `00_START_HERE.md`, `08_DECISIONS.md` in relevantne specifikacije.
2. Za vsako nalogo jasno definiraj obseg, merila, prepovedi in relevantne teste.
3. Codex poroča dejanski diff, preverjanja in omejitve. Nikoli ne piše PASS brez izvedenih testov.
4. Brez deploya, povezovanja obstoječe produkcijske strani, spreminjanja drugih repozitorijev ali izmenjave skrivnosti.
5. Potrjene spremembe dokumentirati v relevantnih *.md; stanje napredka v `06_ROADMAP.md` in `08_DECISIONS.md`.
6. Celotna V3 je v arhivu ChatGPT Project. Pri audit nalogi je potreben dejanski dostop do arhiva, sicer označi, da audit ni mogoč.

Model in stopnjo razmišljanja pred vsako nalogo poda koordinator: glej `docs/CODEX_WORKFLOW.md`.
